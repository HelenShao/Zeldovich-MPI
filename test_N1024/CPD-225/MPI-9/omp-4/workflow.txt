# CPD-225 Test (32 nodes, 1 rank per node) — CPD=225 parameter
# N=1024 grid - Compare 1 OMP thread vs 8 OMP threads (threading test)
# Testing PLT mode with k_cutoff implementation (k_cutoff=1.0, CornerModes=0)
# Compare random number draws and particle ICs between hermitian_3d_matrix_production and zeldovich-PLT
# Both codes print [RNG-DEBUG] output before any FFT for coordinates x,y,z <= 10
# Using ZD_qdensity=1 (density + displacement, narray=2 - just_density=1 mode)
# PLT ENABLED (ZD_qPLT=1), rescaling ENABLED (ZD_qPLTrescale=1)
