11. Compare particle IC files:
$ cd /home/helenshao/InitialConditions/hermitian_3d_matrix_production/test_N4/PLT
# Hermitian IC files: particle_ics/ic_*
# Zeldovich IC files: /home/helenshao/InitialConditions/zeldovich-PLT/output_N4_PLT/ic_*
# 
# Both should contain particle data with:
#   - Density (real part of Array 0)
#   - Displacements: X = imag(Array 0), Y = real(Array 1), Z = imag(Array 1)
#   - Velocities: With PLT enabled, velocities use PLT growth rate f instead of f=1.0
#     Array 2: X-velocity = imag(Array 2) = F_re * f
#     Array 3: Y-velocity = real(Array 3) = (G_re - H_im) * f, Z-velocity = imag(Array 3) = (G_im + H_re) * f
# 
# Compare using the comparison script:
$ python3 compare_particle_ics.py particle_ics/ic_0 /home/helenshao/InitialConditions/zeldovich-PLT/output_N4_PLT/ic_0 4 visualizations/
$ python3 compare_particle_ics.py particle_ics/ic_1 /home/helenshao/InitialConditions/zeldovich-PLT/output_N4_PLT/ic_1 4 visualizations/
# 
# This creates:
#   - Displacement comparison plots (histograms, scatter plots, difference histograms)
#   - Velocity comparison plots (histograms, scatter plots, difference histograms)
#   - Prints statistics (mean difference, max difference, correlation) for each component
# 
# Or compare using binary diff (should match exactly if everything is correct):
# $ diff particle_ics/ic_0 /home/helenshao/InitialConditions/zeldovich-PLT/output_N4_PLT/ic_0
# $ diff particle_ics/ic_1 /home/helenshao/InitialConditions/zeldovich-PLT/output_N4_PLT/ic_1
# 
# Note: Binary diff may show differences due to floating-point representation,
# but the comparison script provides more detailed analysis with tolerance checks
# 
# IMPORTANT: With PLT enabled, velocities should match up to single-precision tolerance
# If velocities differ significantly, check:
#   1. PLT eigenmode interpolation (eigenmode values e.val)
#   2. PLT growth rate f calculation: f = (sqrt(1 + 24*e.val*f_cluster) - 1) / 4
#   3. Velocity storage format: Array 2 = i*F*f, Array 3 = G*f + i*H*f
